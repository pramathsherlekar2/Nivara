SCENARIO LAB · WHAT-IF PLANNING

Test how a disaster situation could escalate.

Scenario Lab is a planning simulator: start from the current Nivara situation, change hazard conditions, and compare possible response priorities. It is not a prediction engine or an authoritative emergency forecast.

LIVE / VERIFIED SIGNALS→NIVARA REPORTS→WHAT-IF SCENARIO→RESPONSE PRIORITIES

Why use it? A responder can ask “What if rainfall intensifies?”, “What if more roads become blocked?” or “What if vulnerable-person requests increase?” and use the resulting comparison to decide what should be verified first.
